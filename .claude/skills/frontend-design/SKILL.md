\# Frontend Design Skill



Siempre responde en español.



Usa únicamente PowerShell en Windows.



Reglas:



\- TypeScript estricto

\- Componentes reutilizables

\- Evitar componentes mayores a 300 líneas

\- Arquitectura modular

\- Responsive design

\- Mobile first

\- Tailwind CSS cuando aplique

\- Evitar lógica compleja dentro de componentes

\- Separar UI, estado y servicios

\- Preferir Zustand para estado global

\- Evitar archivos gigantes
